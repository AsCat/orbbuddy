# 圆伴悬浮角色与授权码

Android 0.4.1 提供三款程序绘制的矢量角色，无外部图片素材，缩放后保持清晰：

| 角色 | 视觉 | 含义 |
| --- | --- | --- |
| 圆圆 | 天蓝色圆脸、红晕、呼吸和眨眼 | 默认伙伴 |
| 芽芽 | 绿色种子形身体、两片大叶 | 轻快与成长 |
| 星星 | 暖黄色五角星身体、琥珀色描边 | 探索与测试 |

在圆伴主界面点选角色后，悬浮球立即换装。角色右下角的状态点表示连接状态：绿色已连接、橙色连接中、灰色暂停。角色可拖动贴边，点击打开本机菜单。

菜单可生成只读授权码；控制码要求先在圆伴主界面保存已安装的可调试 App 包名。口令由本机点击生成，展示 60 秒倒计时，配对成功后立即清除。无法连接或暂停时不会生成口令。点击“撤销 HTTPS 授权”可清除当前口令和会话。

远程读屏成功后，角色会短暂转动视线并闪光；点击完成后会轻弹，滑动完成后会向手势方向侧倾。输入与系统按键也会给出简短反馈。动画只在手机本地悬浮层显示，不进入远程截图。

远程截图前会暂时隐藏整个悬浮层，包括菜单和口令；截图完成后恢复。现有 MCP 令牌独立于临时 HTTPS 授权。此界面仅用于开发测试，不提供支付或下单授权。
