# 实施路线

## 已实现的 MVP

- Android 11+ 开发者侧载客户端：无障碍节点树、按需 JPEG 截图、点击、滑动、输入、返回/主页、应用版本查询。
- 用户启动的前台会话通知、默认网络切换回调和主动重连。
- Go relay：设备主动 WSS 连接、断线自动重连、独立令牌、单设备串行操作、20 秒超时、Streamable HTTP MCP。
- Nginx + systemd 部署示例和模拟设备。Android 与服务端不使用无线 ADB 作为运行链路。

## 下一阶段：稳定性（约 2–4 人日）

- 按厂商实机测试后台限制；服务重启后自动恢复连接。
- 连接状态与错误码更清晰；加心跳、请求指标和日志脱敏。
- 针对多台设备完善配对和令牌轮换，增加自动化断网/重连测试。

## 第三阶段：开源可用性（约 3–5 人日）

- 简化首次配对：扫码配置，设备端显示服务器指纹和会话状态。
- CI 构建、版本发布、可复现 APK、部署脚本；更多 Android 系统与分辨率验证。
- 公开协议版本、兼容矩阵、贡献指南。按需加入本地 stdio 适配器。

## 第四阶段：圆伴悬浮球与高风险操作（约 5–10 人日）

- 悬浮球提供暂停、确认、撤销入口，并明确显示智能体当前会话。
- 为订单、支付等流程增加结构化草稿和手机端本地确认；确认绑定订单摘要、金额、商户和短时效。用户取消或超时即拒绝；敏感字段不经 MCP 返回。
- 提交后展示订单状态及平台允许的撤销/售后入口。无可撤销路径时，在最终确认前明确提示。

这些工作量是单人粗估。当前版本只用于开发测试，不具备支付或下单授权流程。
