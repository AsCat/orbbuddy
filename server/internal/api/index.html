三步接入

运行时无需无线 ADB，也无需电脑与手机处在同一局域网。

01

手机连接

在圆伴 App 配置 WSS 地址与设备令牌，开启无障碍服务和测试会话。

02

手机授权

生成 60 秒内有效的一次性 4 位码。选择只读，或指定已安装的可调试 App 授权控制。

03

HTTPS 调用

以口令换取短期 Bearer 令牌，查询状态、取新截图或执行受限动作。手机可随时撤销。

调用示例

把 0000 换成手机当前显示的口令。口令、令牌和截图不要放入公开日志或 URL。

# 1. 在手机 App 生成口令后配对
curl -sS -X POST https://orb.yuanxuyinli.com/api/v1/auth/pair -H 'Content-Type: application/json' -d '{"device_id":"primary","code":"0000"}'

# 2. 将响应中的 access_token 保存为 TOKEN
TOKEN='粘贴 access_token'
curl -H "Authorization: Bearer $TOKEN" https://orb.yuanxuyinli.com/api/v1/devices/primary/status

# 3. 按需获取最新 JPEG；响应含 X-Captured-At 和 X-Request-ID
curl -H "Authorization: Bearer $TOKEN" https://orb.yuanxuyinli.com/api/v1/devices/primary/screenshot -o screen.jpg

控制会话

仅当手机生成控制口令，且前台是指定的可调试 App 时可以操作：

curl -X POST https://orb.yuanxuyinli.com/api/v1/devices/primary/actions -H "Authorization: Bearer $TOKEN" -H 'Content-Type: application/json' -d '{"request_id":"tap-001","action":"tap","params":{"x":320,"y":600}}'

动作仅支持 tap、swipe、back、home。重复请求 ID 不重复执行。执行 Back/Home 后控制暂停，需手机重新授权才能继续。

会话边界

  • 4 位码一次性使用，60 秒后失效；连续错误 3 次进入冷却。
  • 会话空闲 5 分钟失效、最长 30 分钟；状态查询不续期。
  • 手机 App 可立即撤销；也可调用 POST /api/v1/auth/revoke。
  • 截图不落盘，响应禁止缓存，所有设备接口都需鉴权。

HTTPS API 与 MCP

完整字段与错误结构见 OpenAPI 3 契约。原有手机 WSS 协议和 MCP 入口 https://orb.yuanxuyinli.com/mcp 保持可用；MCP 使用独立令牌。

方法路径权限用途
POST/api/v1/auth/pair手机临时口令换取短期会话
POST/api/v1/auth/revoke会话令牌撤销设备 HTTPS 会话
GET/api/v1/devices/{deviceId}/statusviewer在线、暂停、上次截图时间
GET/api/v1/devices/{deviceId}/screenshotviewer按需获取最新 JPEG
GET/api/v1/devices/{deviceId}/screenshot/metaviewer截图时间与尺寸
POST/api/v1/devices/{deviceId}/actionscontroller有限动作和执行回执
GET/api/v1/operations/{requestId}controller查询操作结果
POST/api/v1/sharesviewer生成 60 秒内有效的一次性截图链接
GET/share/{token}一次性链接读取一张最新截图，使用后失效
智能体注意：能打开网页不代表能提交 POST 或 Bearer 请求头。普通网页抓取工具未必能读取受控截图；可先由已授权客户端调用 POST /api/v1/shares 生成单张只读链接，再交给仅能打开 URL 的客户端。完整操作需要支持认证 HTTPS 请求的连接器，或继续使用现有 MCP 接口。
