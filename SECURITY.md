# Security policy

OrbBuddy can display and operate a personal phone. Please report security issues privately.

## Supported versions

Until the first tagged release, only the current `main` branch receives fixes. After releases begin, this section will list supported version lines.

## Reporting

Use [GitHub private vulnerability reporting](https://github.com/AsCat/orbbuddy/security/advisories/new) when available. If it is unavailable, open a public issue titled “Security contact request” **without** exploit steps, tokens, screenshots, or personal data; a maintainer will arrange a private channel.

Include the affected version or commit, Android version, deployment mode, reproduction steps, and impact in the private report. Do not test against anyone else's device or public OrbBuddy instance without authorization.

The project does not publish screenshots, pairing codes, device tokens, MCP tokens, or input text in issue reports. Remove these before attaching logs.
